# 桌面端「观屏 → 小传」管线

桌面端的核心功能是看着屏幕、鼠标和键盘，替你把一天过成小传。它接在 FATIGUE.md
那层感知之上，算它的内容侧姊妹管线——疲劳管线是内容盲的，这条管线看内容，
所以边界、预算、隐私都得单独讲清楚。

## 分层，延续 pb-os 的铁律：原始数据不出守护进程

采集以五分钟为一窗：几张变化驱动、有上限的截屏（ScreenCaptureKit），加上复用
dozycat-sense 的输入节奏和前台 app。隐私门横在最前面——secure input 亮着、
前台是黑名单 app、或者用户手动按了暂停，整个窗口作废，一张不留。

窗口过了门，进 sequence：把这五分钟的截屏缩略拼成一张 collage，连同 app 序列和
时长交给用户自己的多模态模型，问一句「这五分钟用户在经历什么」，得到一段事实
描述，写进记事本（notebook）——一本本地的明细账，桌面 widget 可以翻。

真正的节流在最后一道：小传蒸馏。睡前或定时，把当天的 sequence 描述串起来再喂
一次模型——「挑出今天真正值得被记住的、不超过三件的小事，用懒猫的口吻写」——
产出才写进 dozycat-core，跨端同步，手机「小传」页看到的就是这个。

密度控制靠这两层分开：sequence 是原料，一天上百条，只进本地记事本，永不同步、
永不直接示人；小传是成品，一天至多三条，经过蒸馏才进 core。明细随时可查，
小传不会灌成流水账。

## 记事本 widget

桌宠旁边的一个轻量窗口，点猫展开：按时间倒序的 sequence 明细，可搜索、可删除
——删除就是本地物理删，因为这些根本没进过 CRDT。哪条值得记，一键收进小传，
算是给蒸馏的遗漏补一手。隐私开关就放在手边：暂停观察 N 小时，应用黑名单。

## BYOK 与预算

模型全部走用户自己的 Key，设置里配，和 iOS 同一套 provider 抽象：OpenAI、
DeepSeek、或任意 OpenAI 兼容端点。成本量级（多模态 mini 级模型）：五分钟一次
collage 描述加每天一次蒸馏，重度使用大约每月一两美元；描述可以用便宜模型，
蒸馏用好模型。没配 Key 时这条管线整个不跑，桌宠退回纯内容盲的疲劳感知——
产品的可用性分级清清楚楚。

## 隐私，比疲劳管线更严一档

截屏只在内存里拼图，发给模型后即弃；本地留下的只有文字描述，不留图（v1 可选留
缩略，默认不留）。secure input、密码管理器、隐私黑名单、私密浏览，命中任何一个，
整个五分钟窗口作废。记事本永不同步；小传经蒸馏才进 core，同步走的是密文（见
MEMORY-SYNC.md）。暂停开关明确可见，菜单栏能看出它在看还是没在看——像 cat-poc
里那只会转头的猫。

## 里程碑

先做 `dozycat-scribe` crate：ScreenCaptureKit 截屏（Rust objc2 或 Swift helper）
加变化检测和 collage 拼图，去重思路复用 cat-poc `cat-sense` 的 MSE。然后是
sequence 描述的多模态调用（Rust 侧 reqwest，或经 pet 的 Swift 层）；记事本
widget（pet-mac 里的 SwiftUI 窗口加本地 SQLite）；每日蒸馏写 core、带「来自
桌面」的标记；最后把隐私门和 sense 打通（secure-input 信号共享），暂停 UI 上线。
